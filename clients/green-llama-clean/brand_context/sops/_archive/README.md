## Why preserved

The framework's origin is legible only when these older versions remain visible. A team member joining GLC content production should be able to trace the trajectory:

1. **Original writing rules** (`WRITING_RULES.md`) — generic Stop Slop rules
2. **First content accuracy response** (`GL_Content_Accuracy_Rules.md`, March 10) — written after the first hallucination flag from Kay
3. **First formal blog SOP** (`BLOG_WRITING_SOP_v1.md`) — added structure (byline, BLUF, FAQ, sources section)
4. **Content quality protocol** (`CONTENT_QUALITY_PROTOCOL.md`) — added the three-level review chain (Author → Matt → Kay)
5. **Blog writing guidelines** (`GL_Blog_Writing_Guidelines_v1.md`, March 30) — added the three-tier source hierarchy and the citation verification process
6. **Canonical April 2026 SOP** (`GL_Blog_Content_SOP_v1_1.md` in the parent folder) — added the [STAT NEEDED] no-placeholder-in-submission rule, legislative citation verification rules, expanded hallucination patterns from April QA

Each step solved a specific problem caught in production. The next inherited and added.
