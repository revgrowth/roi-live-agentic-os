# GLC Reference Archive

Reference documents that are too large or too dated to function as active context but valuable enough to preserve for historical lookup.

## What's archived

| File | Original size | Why archived |
|---|---|---|
| `client-hub.md` | 382KB | Legacy "single source of truth" Client Hub document, likely a Notion or Coda export. Superseded by the brand_context structure (separate voice-profile, positioning, icp, samples, assets, sops). Too large to load into Claude Code sessions without burning context budget. Preserved here so historical content is recoverable. |

## Active reference

The active reference docs live in the parent folder: [`../`](../). Anything in this `_archive/` folder is not part of the active inheritance chain. If a rule in an archived file appears to conflict with the active brand context, the active brand context wins.
